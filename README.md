# Send me an issue

This is a public GitHub repository with one purpose: **a place for you to talk to me through GitHub issues.**

There is no code, library, or app here. The issue tracker is the whole point.

## How to reach me

1. Go to the [Issues tab](https://github.com/DigitalDirtbag/send-me-an-issue-3/issues).
2. Click **New issue**.
3. Write whatever you want to say: a question, an idea, a hello, some feedback, or a request.
4. Submit it. I'll read it and reply there when I can.

## Things to know

- **Everything is public.** Anyone can read your issue and the replies. Don't post passwords, API keys, personal data, or anything else you wouldn't want the world to see.
- **Be kind.** Treat others the way you'd like to be treated. I may close or delete issues that are abusive, spammy, or harmful.
- **No promises on timing.** I'll get to your issue when I can, and I can't guarantee a reply to every one.
- **Pull requests aren't needed.** There's nothing here to contribute to. Just open an issue.

Thanks for stopping by.
